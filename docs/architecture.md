# 系统架构设计

## 总体架构

```
┌─────────────────────────────────────────────────────────┐
│                      云平台 / APP                        │
│                 (MQTT Broker + Web后台)                   │
└──────────────────────┬──────────────────────────────────┘
                       │ MQTT (JSON)
                   ┌───┴────┐
                   │ ESP8266 │  WiFi 通信模块
                   └───┬────┘
                       │ UART3 (115200bps)
┌──────────────────────┴──────────────────────────────────┐
│                    STM32F103C8T6                         │
│                                                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌─────────┐ │
│  │ 传感器    │  │ 控制逻辑  │  │ 通信任务  │  │ 显示    │ │
│  │ 采集任务  │  │ 任务      │  │ 任务      │  │ 任务    │ │
│  └─────┬────┘  └────┬─────┘  └────┬─────┘  └────┬────┘ │
│        │            │              │              │      │
│  ┌─────┴────────────┴──────────────┴──────────────┴────┐ │
│  │                  FreeRTOS 调度器                      │ │
│  └─────────────────────────────────────────────────────┘ │
│                                                          │
│  I2C1: OLED + BH1750    ADC1: 土壤湿度                   │
│  TIM2: DHT22时序        GPIO: 继电器x3, 蜂鸣器           │
│  UART1: 调试串口        UART3: ESP8266                   │
└──────────────────────────────────────────────────────────┘
```

## 任务设计 (FreeRTOS)

| 任务名称 | 优先级 | 栈大小 | 周期 | 功能 |
|---------|--------|--------|------|------|
| SensorTask | 3 | 512B | 2000ms | 轮询所有传感器，写入数据队列 |
| ControlTask | 4 | 256B | 1000ms | 读取传感器数据，阈值判断，控制执行器 |
| CommTask | 2 | 1024B | 5000ms | 数据上云，接收远程指令 |
| DisplayTask | 1 | 256B | 500ms | OLED刷新显示 |
| WatchdogTask | 5 | 128B | 10000ms | 系统健康检查，喂狗 |

## 数据流

```
传感器 → [SensorTask读取] → 消息队列 → [ControlTask判断]
                                            ↓
                                      执行器动作
                                            ↓
                              [CommTask] → JSON封装 → MQTT上云
                              [CommTask] ← MQTT指令 ← 云端/APP
```

## 控制策略

- **灌溉**：土壤湿度 < 30% → 开水泵；> 60% → 关水泵（带最小灌溉间隔保护）
- **补光**：光照 < 1000 lux 且处于白天(6:00-18:00) → 开启补光灯
- **通风**：温度 > 35°C → 开风扇；< 28°C → 关风扇
- **安全**：水泵连续运行 > 30分钟 → 强制关闭 + 报警
